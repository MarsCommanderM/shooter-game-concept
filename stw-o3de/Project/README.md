# STW Project

Repository-owned O3DE project: source assets (`Assets/`), levels (`Levels/`),
and runtime configuration for the native STW game.

> ## PRODUCTION QUALITY BAR: REALISTIC CINEMATIC. NOT BLOCKOUT. NOT A PROTOTYPE.
>
> STW targets a hyper-realistic, cinematic AAA native 3D multiplayer FPS.
> Over 100 prototypes of this game already exist — this is not another one.
> Blockout geometry, placeholder materials, debug meshes, and temporary
> lighting are development tools only; never treat them, describe them, or
> ship them as a finished asset or level. Follow
> [Project Visual Forge](../Docs/README.md) for the reproducible visual
> production pipeline and evidence standard before any asset or level edit,
> and [`../../docs/STW_PRODUCT_VISION.md`](../../docs/STW_PRODUCT_VISION.md)
> for the authoritative product target.
