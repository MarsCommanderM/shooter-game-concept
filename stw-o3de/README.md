# STW O3DE foundation gate

This directory records the O3DE production-migration gate without changing the
existing native STW game. The gate is currently **BLOCKED** by the execution
host, not approved and not rejected on engine merit.

The selected upstream is O3DE 26.05.0 at the immutable revision recorded in
[`O3DE_VERSION.md`](O3DE_VERSION.md). The factual findings, STW ownership map,
and continuation procedure are in [`MIGRATION.md`](MIGRATION.md).

## Deliberately absent

There is no checked-in `Project/` or `Gems/` tree yet. O3DE requires those
trees to be generated by its pinned CLI. On this host the unmodified CLI stops
while importing its required Python packages, and the official bootstrap
cannot run because CMake is absent. Manually copying or inventing a project
layout would violate the gate.

The existing game under `stw-engine/` remains the only production game. No
O3DE runtime, launcher, scene, gameplay module, or network implementation is
authoritative while this gate is blocked.

## Host preflight

Run the read-only checker on a proposed O3DE workstation before generating any
project files:

```bash
bash stw-o3de/Scripts/verify-host.sh
```

The checker installs nothing and writes nothing. It rejects software Vulkan
devices because the visual gate requires a real GPU.
