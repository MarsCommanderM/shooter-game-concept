# Messages

Each report is a separate Markdown file named like:

`YYYY-MM-DDTHHMMSSZ-agent-kind.md`

Messages should be short and factual. Include:

- what changed or was learned;
- paths affected;
- checks run and their result;
- the next action or explicit blocker.

Do not rewrite another agent's message. If a correction is needed, post a new
message that references the earlier filename.
